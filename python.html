Lecture 01

자료형, 연산자, 문자열 & 슬라이싱

파이썬의 가장 기본적인 데이터 타입인 정수(int), 실수(float), 문자열(str)과 기초 연산자, 그리고 문자열 인덱싱/슬라이싱 문법을 학습합니다.

기본 자료형 & 연산자

  • 정수형(int): 3, 100
  • 실수형(float): 3.14, -120.22
  • 사칙연산: +, -, *, / (나눗셈 결과는 float)

이스케이프 코드 & 함수

  • \n (줄바꿈), \t (탭 간격)
  • \', \", \\ (특수문자 출력)
  • len(a): 문자열의 길이(글자 수) 구하기
  • 문자열 반복: "ㅋ" * 12
인덱싱과 슬라이싱 (Indexing & Slicing) 
a = "Life is too short, You need python"

# 인덱싱 (Indexing - 특정 위치 지정)
print(a[0])      # 'L' (첫 번째 글자)
print(a[3])      # 'e' (네 번째 글자)
print(a[-1])     # 'n' (맨 뒤에서 첫 번째 글자)

# 슬라이싱 (Slicing - 범위를 지정 [시작:끝index+1])
print(a[0:4])    # 'Life' (0번부터 3번까지)
print(a[12:17])  # 'short'
print(a[:17])    # 'Life is too short' (처음부터 16번까지)
print(a[23:])    # 'need python' (23번부터 끝까지)
print(a[:])      # 전체 문자열 복사
Lecture 02

문자열 포매팅 & 실습

문자열 내부에 변수나 원하는 값을 삽입하는 여러 기법(% 포매팅, format() 메서드)과 날짜 데이터 슬라이싱 응용을 다룹니다.

% 포매팅 코드 규칙

%s : 문자열 (String)
%d : 정수 (Integer)
%f : 부동소수점 (Float)
%.2f : 소수점 둘째 자리
포매팅 방식 및 슬라이싱 실습 
# 1. % 포매팅 사용법
grade = 2
score = 3.8
print("나는 %d학년입니다." % grade)
print("성적은 %.2f점 입니다." % score)

# 2. .format() 메서드 사용법
earth, moon, km = "지구", "달", 384000
print("{0}와 {1} 사이의 거리는 평균 {2}km입니다.".format(earth, moon, km))
# 이름(Key)을 직접 지정하는 방식
print("{earth}와 {moon} 거리는 {km}km입니다.".format(earth="지구", moon="달", km=384000))

# 3. 날짜 문자열 슬라이싱 실습
p = "20260916맑음28.5"
print("year: " + p[:4])      # 2026
print("month: " + p[4:6])    # 09
print("day: " + p[6:8])      # 16
print("Weather: " + p[8:10]) # 맑음
print("temp: " + p[-4:])     # 28.5
Lecture 03

고급 포매팅, 문자열 메서드 & 사용자 입출력

문자열의 정렬, 공백 제거, 대체 등 강력한 내장 메서드와 input() 함수를 사용해 동적으로 사용자의 값을 입력받는 방법을 배우게 됩니다.

자주 쓰는 문자열 내장 메서드

.upper() / .lower() : 대/소문자 변환
.strip() / .lstrip() : 양쪽/왼쪽 공백 제거
.replace(old, new) : 문자열 치환
.split() : 공백 또는 구분자로 분할 (리스트 반환)
"구분자".join(iterable) : 문자열 합치기
.count('a') : 특정 문자 개수 세기
고급 포매팅 정렬 & input() 실습 
# 1. 정렬 및 채우기
print("{0:<10}!".format("어서와"))   # 왼쪽 정렬: '어서와       !'
print("{0:>10}!".format("어서와"))   # 오른쪽 정렬: '       어서와!'
print("{0:-^19}".format("어서와"))   # 가운데 정렬 후 '-' 채움

# 2. 문자열 변환 및 조인
monday = "   월요일 좋아   "
print(monday.strip())               # '월요일 좋아' (공백 제거)
print(monday.replace("좋아", "싫어")) # '   월요일 싫어   '

# 3. input() 사용자 입력 받기 (입력값은 기본적으로 str!)
name = input("이름을 입력하세요: ")
print(name, "님 반갑습니다")

# 숫자로 계산하려면 int() 또는 float()로 형변환 필수!
num1 = int(input("첫번째 숫자를 입력하세요: "))
num2 = int(input("두번째 숫자를 입력하세요: "))
print("두 숫자의 합은", num1 + num2, "입니다")
Lecture 04

탐색, 리스트(List) & 튜플(Tuple)

순서가 있고 수정이 가능한 리스트(List) 자료형의 다양한 다루기(추가, 삭제, 정렬)와 요소 변경이 불가능한 튜플(Tuple)의 차이점을 파악합니다.

리스트 주요 메서드 요약

.append(x) : 맨 뒤에 x 추가
.sort() : 오름차순 정렬
.reverse() : 리스트 순서 뒤집기
.insert(i, x) : i 위치에 x 삽입
.remove(x) : 첫 번째 x 값 삭제
.pop() / .pop(i) : 요소 꺼내고 삭제
.extend(list) : 리스트 확장
del a[i] : i번째 인덱스 삭제
리스트 조작 및 튜플 실습 
# 1. 문자열 탐색: find vs index
a = "You're my soda pop."
print(a.find("x"))   # -1 (찾는 문자가 없으면 -1 반환)
# print(a.index("x")) # Error 발생!

# 2. 리스트(List) 생성 및 수정
food = ['pizza', 'chicken', 'burger']
food.append('hotdog')       # 맨 뒤 요소 추가
food.insert(1, 'salad')      # 1번 인덱스 위치에 추가
food.remove('pizza')        # 'pizza' 값 직접 삭제
print(food)

num = [21, 2, 27, 24, 8]
num.sort()                  # 정렬: [2, 8, 21, 24, 27]
print(num)

# 3. 튜플(Tuple) - ()로 선언하며, 요소를 변경/삭제 불가!
a = (1,)                    # 요소가 1개일 땐 컴마(,) 필수!
b = (1, 2, 3, 4, 5)
d = (33, 44, ('d', 'e'))    # 중첩 튜플 가능
Lecture 05

딕셔너리, 집합 & 제어문 (if, while, for)

Key-Value 쌍인 딕셔너리, 중복 없는 집합(Set) 구조와 조건에 따라 흐름을 제어하는 조건문(if-elif-else), 반복문(while, for)을 종합 학습합니다.

Dictionary & Set

  • Dictionary: {Key: Value} 형태. 중복 키 불가.
  • .keys(), .values(), .items() 사용
  • Set (집합): 중복 허용 안 함, 순서 없음 (& 교집합, | 합집합)

제어문 (Control Flow)

  • 조건문: if → elif → else
  • 반복문: while 조건: (조건이 참일 동안 반복)
  • for문: for 변수 in 범위/리스트:
  • range(1, 10): 1부터 9까지의 숫자 범위 생성
딕셔너리 & 제어문 코드 실습 
# 1. 딕셔너리 예시
pair = {"짜장면": "탕수육", "치킨": "맥주"}
print(pair.get("치킨"))        # '맥주'
print("떡볶이" in pair)        # False

# 2. if-elif-else 성적 판별
score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("F")

# 3. for문과 range를 활용한 구구단 (중첩 루프)
for i in range(2, 10):         # 2단 ~ 9단
    for j in range(1, 10):     # 1 ~ 9 곱하기
        print(i, "x", j, "=", i * j)
